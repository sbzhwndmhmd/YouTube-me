YouTube Touch — نسخه اولیه پروژه اندروید

هدف: Android 5.1.1 (API 22) و بالاتر، پردازنده ARM/ARMv7
حداقل نسخه اندروید: 5.0 (API 21)

این نسخه یک پوسته سبک و لمسی برای وب‌سایت رسمی موبایل یوتیوب است؛ ویدئوها را از سرورهای خود YouTube پخش می‌کند و از API غیررسمی یا دانلود ویدئو استفاده نمی‌کند.

محدودیت‌ها:
- این برنامه کلاینت رسمی YouTube نیست و تمام قابلیت‌های برنامه رسمی را تضمین نمی‌کند.
- ورود به حساب گوگل ممکن است داخل WebView توسط گوگل مسدود شود؛ در این حالت از گزینه «باز کردن در مرورگر» استفاده کنید.
- عملکرد پخش به نسخه Android System WebView/Chrome و پشتیبانی سرویس یوتیوب از مرورگر قدیمی وابسته است.
- Android 5.1.1 بسیار قدیمی است؛ ممکن است برخی قابلیت‌های جدید YouTube دیگر روی آن کار نکنند.

ساخت APK:
1) پروژه را در Android Studio باز کنید.
2) compile SDK 29 و Android Gradle Plugin 3.6.4 را نصب کنید.
3) از Build > Build APK(s) خروجی بگیرید.
4) فایل خروجی معمولاً در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.
